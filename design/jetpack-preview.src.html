What we need to agree on

My proposal is in bold. Tell me what you want to change and I will update the draft before starting on the WPF library.

Focus indicator

The original had an invisible focus (FocusVisualBrush #00000000). That is a problem for keyboard users.

Proposal: 1 px ring in the accent highlight, and fields get an accent border. Toggle it at the top to compare.

Font size

Silverlight used 11 px for controls. On modern screens in WPF that looks small.

Proposal: 12 px for controls, headings unchanged. Both can be seen with the buttons at the top.

Accent colours

JetPack has three accent sets: green, orange and blue. MahApps has 23 and can make a set from one colour.

Proposal: Green by default, orange and blue built in, plus a generator that makes all gradients from one colour.

Window title bar

A new part that did not exist in Silverlight. Three variants are shown on the Window tab.

Proposal: Dark title bar (the same gradient as the DataGrid header), so the light menu bar stands out below it.

Light and dark inputs

The original has both "White" and "Dark Gray" TextBox and PasswordBox.

Proposal: light by default, dark as the named style JetPack.Styles.TextBox.Dark, also for NumericUpDown and ComboBox.

Typeface

Trebuchet MS ships with Windows, so it matches the original without bundling a font.

Proposal: keep Trebuchet MS, with Segoe UI as the fallback.

Light/dark base

MahApps has Light and Dark base themes. JetPack only exists in the grey textured version.

Proposal: only the original grey base in version 1. A darker variant can come later.

Library structure

For step 2: a standalone library with the same structure as MahApps, or a theme on top of the MahApps.Metro package.

Proposal: a standalone library, JetPack.Wpf (net8.0-windows), modelled on MahApps' controls with new templates.
